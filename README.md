# FIT — Personal Fitness Platform

Premium black + neon-green fitness companion built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Current foundation

- Responsive dashboard and navigation
- Workout plan view with completion tracking
- Nutrition log with add-meal interaction
- Progress summary

## Product direction

FIT supports weight loss, muscle gain, and fitness maintenance with difficulty adapted to beginner, intermediate, and advanced users. English-only interface.

> Data currently stays in browser memory and is sample starter data. Authentication, persistent database storage, personalized calculations, and production integrations are not connected yet.
